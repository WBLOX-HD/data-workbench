# 脱敏策略

## 威胁模型

目标：把一份含真实编号/批次/日期/备注的数据交给同事或外部顾问做统计分析，
但不暴露可反查到具体样本、批次、客户或产线的信息。

非目标：防御拥有原始数据、计算资源和盐值的攻击者；脱敏不等于加密。

## 默认规则

| 角色 | 识别方式 | 默认替换 | 可选项 |
|---|---|---|---|
| 编号 | 表头关键词 / 高唯一性文本 | `P-` + SHA-256(salt‖值) 前 14 位 | hash / sequence / keep |
| 批次/分组 | 文本且唯一值 2–200 | `G-` + 哈希 | hash / sequence / keep |
| 日期 | 表头或值形如 YYYY-MM-DD / Excel 序列号 | 统一偏移 **7 的倍数天**（保留星期） | 指定偏移天数 |
| 其他文本 | 未被识别为编号/批次/日期 | `T-` + 哈希 | mask / keep / drop |
| 数值 | — | 原样保留 | — |

## 时间语义

- 默认偏移取 7 的倍数，**星期几与“第几周”关系保留**；
- **月份/季度/年份会平移**，不能用脱敏后的日历月份做月报同比；请改用“相对第 N 周/相对基线”；
- 保留原始时间格式与时分秒（`2026-01-01 08:30` → `2026-01-11 08:30`）；
- Excel 日期序列号会按天数偏移，不会被当成普通数值漏掉；
- 纯数字长编号（如 12 位流水号）也会被假名化，不会因为“是数字”而跳过。

## 数值与可识别性

- 数值本身不做扰动，统计/能力/SPC 结论保持有效；
- 但“唯一容量值”“小组均值”等仍可能反推个体，公开报告建议对组 n<5 合并，或对可识别数值列做分箱/抖动。

## 注意事项

- 盐值默认随机生成，不同导出之间不可关联；需要跨文件关联时，手动使用同一盐值。
- 映射表保存在内存中，用于核对；默认不导出。
- 日期偏移会改变“具体日期”，但保留间隔、顺序和班次关系。
- 文本掩码会破坏备注语义；只做数值分析时建议 `textMode: 'drop'`。
- 数值若本身可识别（例如唯一容量值），仍可能被推断；高敏感场景请同时做分箱或加噪。
