# Data Workbench（通用数据分析工作台）

一个**独立于具体行业/公司**的本地数据分析工作台项目，目标是：

- 导入 Excel / CSV，自动识别字段角色（编号、分组、日期、指标）；
- **一键脱敏**：编号/批次/日期/文本按策略替换，数值保持分析价值；
- 通用统计：描述统计、正态性、过程能力、SPC、假设检验、相关、帕累托；
- 生成可分享的分析报告（Word / HTML / CSV）；
- 所有数据只在本地处理，不上传、不落盘（导出除外）。

> 本项目与「电芯数据工作台 / battery-workbench」完全独立：
> 不含任何公司编码规则、真实数据、客户名称或行业专属质量规则。

- `src/core/desensitize.js`：SHA-256 确定性假名化、分组映射、日期偏移、文本掩码；

## 脱敏设计

默认策略：

| 字段类型 | 默认处理 | 说明 |
|---|---|---|
| 编号/序列号 | `P-<hash>` 假名 | 同一文件内保持一致，换 salt 不可关联 |
| 批次/分组 | `G-<hash>` 假名 | 保留组结构，不能反查真实批次 |
| 日期 | 统一偏移 N 天 | 保留时间间隔与顺序 |
| 其余文本 | `T-<hash>` 掩码或清空 | 可配置保留/掩码/删除 |
| 数值 | 原样保留 | 统计结果不失真 |

- 使用 SHA-256，盐值随机生成，默认不保存；
- 映射表只在内存中，便于核对；导出文件不含真实值；
- 不对数值做扰动，避免改变能力/SPC 结论。

